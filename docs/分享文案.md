# 食光小卡分享文案

## 抖音口播版（约 45–60 秒）

最近看了邵艾伦的薄肌相关分享，还有和孙宇晨的对谈，我有了个想法：把每天记录饮食这件事做得轻松一点。

于是我用 AI 做了一个小工具，叫「食光小卡」。

第一次填好基础资料，以后吃饭时拍张照发过去就行。不用每顿再打字解释这是什么菜、多少克。AI 会尽量自己识别食物、查营养参照，估算这一顿的热量，更新今天已经记录了多少，再做成一张好看的小卡片，给一点下一餐的搭配建议。

像肠粉、烤串、烧饼配汤这种中餐，也会按食材和做法拆开估算。当然，一张照片看不见所有用油和份量，所以它会保留范围，把哪些有来源、哪些是推测写清楚。

我希望它能让记录饮食更容易坚持，也更少一点负担。Skill 已经放到 GitHub，感兴趣可以拿去试试。
